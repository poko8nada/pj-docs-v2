# Prepare

There are policies and rules for each current project phase. Depending on the phase, output is also required.

## Instructions

1. we should have already decided on the project phase. (if not, ask the user)
2. Read the corresponding reference file below.
3. Internalize the rules - Don't summarize the rules or repeat them to your users.
4. Follow the reference file if you need the output.

## References

  - For website → read `references/design-web.md`
- Phase `build` → read `references/build.md`
- Phase `refine` → read `references/refine.md`
