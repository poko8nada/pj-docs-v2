# grain

Surface character through axes (not upfront palette/fonts). Append-only under `findings/grain/`. No GitHub issues. No product code edits — return briefs.

Axes / audit / craft / formats → `references/axes.md`, `audit.md`, `craft.md`, `formats.md`. Each Step is one unit unless user allows a short path.

## Steps — pick Mode

Recommend Mode; agree before continuing.

| Mode    | When                                 | Path                            |
| ------- | ------------------------------------ | ------------------------------- |
| Define  | No agreed style language             | → closing Audit → persist       |
| Audit   | UI/look exists; needs review         | Main: persist; or closing Audit |
| Improve | Fixes after Audit / named polish     | → closing Audit → persist       |
| Create  | Grain agreed; new surface to specify | → closing Audit → persist       |

### Define

1. Inspect context (issues, prior grain/look).
2. Propose axes (no hex) → yes/edit/no.
3. Derive tokens → yes/edit/no.
4. Closing Audit (chat only).
5. Write `# Grain` + `# Tokens` + Audit → handoff.

### Audit

1. Fix target.
2. Run `references/audit.md` (Observation→Impact→Suggestion) → yes/edit/no.
3. Main Audit only: write findings + handoff. Closing Audit: return to parent Mode persist.

### Improve / Create

1. Confirm grain.
2. Brief via `references/craft.md` → yes/edit/no.
3. Closing Audit.
4. Write brief + Audit → handoff.

## Format

Shapes → `references/formats.md`. Handoff: Topic / Path / Why / Summary / Axes touched.

## Limits

- Do not start with color swatches or font lists.
- Do not skip closing Audit after Define / Improve / Create.
- Do not overwrite prior findings without user ask.
- Do not edit issues or product code.
