# discussion — judgment

Read when Goal / Discover / Build orientation is unclear. Not required every turn.

## Goal

1. Goal is the north star (What / Goal / Non-goal) — not a gate before Discover.
2. Goal is shaped through discussion and Discover; some Discover axes may agree while Goal is open.
3. Once Goal is agreed, reopen only on strong need. Default return rethinks Discover.
4. Soft comments may imply continuation, not only a closed pointer.
5. Goal + Discover agreed → Build-oriented focus from Roadmap / Test / Deploy and the code.
6. Return from hands-on to rethink Discover is normal.

## Anchors

- Early → advance Goal and/or Discover together; soft/media waits for focus lock + hands-on
- Open-ended soft → focus = continue that soft in hands-on
- Goal open, some Discover agreed → keep Discover as input to Goal
- Both agreed, no Build → focus = open Build
- Both agreed, Build open → read code + axes → concrete Build focus
- Code vs axes disagree → Discover rethink or Build-axis update in hands-on
- Harness / typo / meta → `/chore`
- Fuzzy topic → no label yet. Topic change → re-agree and re-run `scope`
