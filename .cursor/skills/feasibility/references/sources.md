# feasibility — sources

## Tiering

- **L1:** Official docs, RFCs, specs; Context7; library source
- **L2:** Major-project eng blogs, maintainers, peer-reviewed; official issues with maintainer replies
- **L3:** Major tech media, conference talks; community blogs
- **L4 (confirm via L1–L3):** Q&A, social, unverified blogs

## Roles (per topic)

1. **Official** — Context7 first; else `web_search_exa` + `WebFetch` (Exa 429 → `WebSearch`)
2. **Practice** — eng blogs / maintainers / OSS — same search tools
3. **Failure** — issues / postmortems / gotchas — search with “issue”, “bug”, “gotcha”, “pitfall”

Three sources with **different roles** is the minimum. Do not use this repo’s app `src` as ecosystem research truth.
